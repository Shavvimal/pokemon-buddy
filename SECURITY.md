# Security

Pokémon Buddy runs inside Claude Code as a mod. It makes HTTPS requests to
GitHub and writes only to its own plugin store. It runs no commands and reads
no files.

## Reporting a vulnerability

Do not open a public issue. Use GitHub's
[private vulnerability reporting](https://github.com/Shavvimal/pokemon-buddy/security/advisories/new)
for this repository. Say what you found, how to reproduce it, and which
version you used. You will get a reply within 7 days.

## Supported versions

Only the latest release gets fixes.
